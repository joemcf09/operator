Operator - Ferry, Cargo & ACMI

Operator runs a small web server on your own machine and opens its interface in
your browser. Nothing is uploaded anywhere. Your company is stored in a single
file in the "save" folder inside the installation directory.

When you start Operator a console window appears and stays open while you play.
Closing that window shuts the program down.

Windows may warn about an unrecognised publisher, because this build is not
code-signed. Choose "More info" and then "Run anyway" if you are happy to
continue.

Connecting a simulator
  Microsoft Flight Simulator 2020 / 2024 and Prepar3D connect through SimConnect
  and must be running on this PC.
  X-Plane 11 and 12 need nothing installed; Operator listens for datarefs over
  UDP port 49000, and the simulator may run on another machine on your network.

SimBrief
  Enter your SimBrief username in Settings to send flights to SimBrief and pull
  the OFP back automatically.
